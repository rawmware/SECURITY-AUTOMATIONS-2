What this is

    Run the real engines locally

    1. Clone the repo and install.

      git clone https://github.com/rawmware/SECURITY-AUTOMATIONS-2.git
cd SECURITY-AUTOMATIONS-2
pip install -e .

    2. Point it at your targets. One YAML file: domains, zones, hosts, repos, cloud accounts.

      cp targets.example.yaml targets.yaml
$EDITOR targets.yaml

    3. Run a scan. Engines execute, the pipeline scores and correlates, findings land as JSON.

      aegis scan --targets targets.yaml --out findings.json

    4. Or bring up the whole stack — scheduler, dashboard, alerting.

      docker compose up
